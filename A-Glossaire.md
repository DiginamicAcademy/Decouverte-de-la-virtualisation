# Glossaire

| Terme | Définition |
|---|---|
| **Cluster** | Regroupement de plusieurs machines (serveurs, équipements réseau, baies) pour garantir disponibilité et qualité de service |
| **Datastore** | Conteneur logique de stockage composé de plusieurs périphériques |
| **DRS** | *Distributed Resource Scheduler* (VMware) : répartition automatique des VM entre les nœuds |
| **Failover** | Basculement du traitement d'un nœud vers un autre |
| **FT** | *Fault Tolerance* : VM exécutées en double, sans interruption en cas de panne |
| **HA** | *High Availability* : redémarrage des VM sur un autre hôte en cas de panne |
| **Hôte** | Serveur physique qui fournit ses ressources aux VM |
| **Hyperconvergence** | Agrégation du calcul, du stockage, du réseau et de la virtualisation de plusieurs serveurs |
| **Hyperviseur** | Logiciel qui exécute et administre les machines virtuelles |
| **IaaS / PaaS / SaaS** | Infrastructure / Plateforme / Logiciel *as a Service* |
| **iSCSI** | Stockage en mode bloc transporté sur IP |
| **NAS** | *Network Attached Storage* : serveur de fichiers réseau |
| **SAN** | *Storage Area Network* : réseau de stockage en mode bloc |
| **SDS** | *Software-Defined Storage* : stockage virtualisé |
| **SLA** | *Service Level Agreement* : engagement contractuel de niveau de service |
| **Surallocation** | Allocation aux VM de plus de ressources qu'il n'en existe physiquement |
| **vCPU / vRAM** | Processeur / mémoire virtuels attribués à une VM |
| **VDI** | *Virtual Desktop Infrastructure* : virtualisation des postes de travail |
| **vMotion** | Migration à chaud d'une VM entre deux hôtes (VMware) |
| **VM** | *Virtual Machine* : machine virtuelle |
| **VMM** | *Virtual Machine Manager* : composant de gestion des VM |
